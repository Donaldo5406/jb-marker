# 음악 베드 (드롭인)

렌더 서비스(`gateway/video/render.py:_resolve_music`)는 이 디렉터리에서
`bed.m4a` / `bed.mp3` / `bed.wav` / `bed.aac` / `bed.ogg` 중 첫 파일을 음악
베드로 사용한다. 파일이 없으면 **무음**으로 렌더된다(비차단).

## 라이선스 규약 (필수)
- **CC0 / 로열티프리만** 허용. 출처·라이선스를 아래에 기록할 것.
- 바이너리 트랙은 레포에 커밋하지 않는다(이 README만 추적). 배포 이미지/런타임에 드롭인.

## 동봉 트랙 (현재)
- **트랙**: `bed.m4a` — 따뜻한 Cmaj 앰비언트 패드(22s)
- **생성**: `bash make_bed.sh` (ffmpeg 사인 합성 — C3·G3·C4·E4 + 트레몰로·에코·필터·페이드)
- **출처/작곡**: 절차적 합성(서드파티 소스 없음). 본 레포에서 생성.
- **라이선스**: CC0 / Public Domain (저작권 대상 아님)
- 레벨은 렌더(`render.py`)의 `loudnorm`이 -18 LUFS로 자동 보정하므로 절대 음량은 무관.

## 교체(다른 트랙 드롭인)
1. CC0 트랙을 `bed.m4a`(권장) 등으로 이 폴더에 둔다(첫 매칭 우선).
2. 출처를 위 형식으로 기록할 것(CC0 / Public Domain 만 허용).
