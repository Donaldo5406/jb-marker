## A. 평문 버전 (문서 본문에 그대로 붙여넣기)

```
[기능 변경이력] — 예선 명세서(2026.06.14) 대비 본선 변경분 (C=추가, U=수정, D=삭제)

1) 2026.07.04 | D | 대상: F5 발송(결제·권한 표면)
   변경 내용: /pricing 페이지·랜딩 '결제' 메뉴·데모 결제 모달·POST /deploy/demo-payment·_state.dev_pass 제거
   변경 사유: 은행 내부 준법 마케팅 코파일럿이라는 제품 목적에 소비자 결제 서사가 불일치
   전후 차이: (전) 발송 확정 시 결제 모달 → (후) 모달 없이 바로 진행. 엔타이틀먼트 토글(Setting)은 유지

2) 2026.07.04 | C | 대상: 데모(Mock) 파이프라인 체감
   변경 내용: DEMO_LATENCY_MS(env, 기본 0=끔)로 mock 응답에 자연 레이턴시 부여
   변경 사유: mock 즉답이 라이브 데모에서 인위적으로 보임
   전후 차이: (전) 즉답 → (후) 응답 길이 비례 자연 대기(텍스트 상한 1.2초 / 이미지 상한 1.6초)

3) 2026.07.04 | U | 대상: F2 디자인 교정·F3 다국어
   변경 내용: 교정(revise) 재베이크를 image-edit(img2img)로 전환 + vi/en/zh 언어 예시 3종 추가
   변경 사유: 재생성마다 포스터 전체가 바뀌어 '카피만 교정' 서사가 약하고, 비국문 언어 품질 격차 존재
   전후 차이: (전) 교정 시 포스터 통째 변경, en/vi/zh는 폴백 → (후) 아트 유지·텍스트만 교체, 4개 언어 동급 품질

4) 2026.07.04 | C | 대상: F4 준법 사전검토 (신규 RC 노드)
   변경 내용: 검토 순서에 RC(논란) 노드 추가(R0→R1→R2→RC→R3). 2티어 블랙리스트 결정론 안전망 + LLM 맥락 판정 + 라이브 비전의 3경로 감지
   변경 사유: 배포 전 한국 사회 논란·평판 리스크를 정치적 판단 없이 중립적으로 사전 감지
   전후 차이: (전) 법률·시각·번역만 검토 → (후) '논란' 단계 추가, ControversyCard 표시, 심각도 티어링으로 게이트 합류(치명→발송 잠금). mock 데모도 결정론 완주

5) 2026.07.04 | U | 대상: F4 / RC 라이브 비전 경로
   변경 내용: 블랙리스트에 visual_symbols(욱일기·전범기·나치 상징·집게손·일베 제스처) 신설, Gemini 비전이 그림·손동작까지 판정
   변경 사유: 욱일기는 문자열이 아닌 그림으로도 등장하고, 논란 제스처는 애초에 텍스트가 아니라 OCR/블랙리스트로 원천 탐지 불가
   전후 차이: (전) 텍스트/OCR 매칭만 → (후) 도안·제스처까지 판정(라이브 best-effort, 제스처는 과잉판정 방지 위해 경고). mock·결정론 게이트는 불변

6) 2026.07.04 | C | 대상: F2 디자인 생성 톤 (브랜드 컨텍스트)
   변경 내용: JB 브랜드 지식 팩(references/brand/jb_group.yaml) + 저변동 계층만 렌더하는 brand_context 신설(products 섹션은 프롬프트 주입 금지)
   변경 사유: 생성 소재 기본 톤을 JB CI로 수렴시키되 시의성(상품·금리)은 런타임 SSOT로 분리
   전후 차이: (전) 브랜드 톤 미주입 → (후) 지시 없을 때만 JB CI 톤 수렴(사용자 지시가 항상 우선)

7) 2026.07.04 | U | 대상: F2 디자인 프롬프트·F6 이력 표시
   변경 내용: Design S1 프롬프트 말미에 브랜드 블록 append(디자인 토큰 우선), History 데모 표시 제목 3건을 현행 실상품으로
   변경 사유: 지시 없을 때만 톤 수렴 · 데모 표시 제목이 현행 실상품과 불일치
   전후 차이: (후) History 목록의 데모 제목이 현행 실상품명으로 표시(표시 전용)

8) 2026.07.04 | C | 대상: 신규 화면 /architecture '동작 원리'
   변경 내용: 시스템 흐름 8단계 자동 루프 다이어그램 + AI 에이전트 루프 + 기술 스택 표 + 랜딩 네비 항목
   변경 사유: 심사 대응 — 풀스택 구조·Agent 활용 방식을 비개발자도 제품 안에서 이해하도록
   전후 차이: (전) 없음 → (후) 랜딩 상단 '동작 원리' 메뉴 + 애니메이션 아키텍처 페이지

9) 2026.07.04 | C | 대상: F7 스튜디오 자료 업로드 소스화 (본선 신설)
   변경 내용: FileTree 업로드 버튼(Brain·Design·Review), 업로드 파일을 {studio}/uploads/에 저장해 AI 참조. 용량 캡·확장자·인젝션 가드
   변경 사유: 각 스튜디오가 AI 소비 데이터(기획서/계획·카피·심의 소재)를 자율 업로드 가능토록
   전후 차이: (전) 업로드 불가 → (후) 스튜디오별 업로드 버튼. mock: 트리거 이미지 업로드 시 Review 결정론 적발(발송 잠금) 재현

10) 2026.07.04 | C | 대상: F4 준법 사전검토 (결과 시각화)
    변경 내용: 신설 엔드포인트 GET /runs/{id}/review-highlight, verdict location 비파괴 확장(bbox/image), HighlightFrame. Mock=정적 좌표 / Live=비전·OCR 소스 교체
    변경 사유: 심의 결과가 텍스트 카드로만 설명돼 '이미지의 어디가 문제인지'를 시각적으로 못 짚음
    전후 차이: (전) 카드 텍스트만 → (후) 검토 포스터 위 위반 문구에 마커펜(치명 빨강/경고 노랑)+번호 핀이 근거 카드와 연결, 카드/시각 뷰 토글. 좌표 없으면 카드뷰로 축퇴
```
