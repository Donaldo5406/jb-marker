## 결과 (강화 전 대비)
| | 강화 전 (live-real-api) | 강화 후 (이 폴더) |
|---|---|---|
| 금리 표현 | 밋밋한 한 줄 텍스트 | 구조화된 금리 하이라이트 카드 |
| 밀도 | 사진 + 텍스트 | 실제 은행 포스터급 컨테이너·악센트 |

- **A 튼튼정기예금**(4:5): 골드 헤드라인 3단 + 금리카드(연 3.5% 대형) + CTA 내장
- **B 청년도약적금**(4:5): 금리카드(2.80%+0.50%p→3.30%) 브래킷 악센트
- **C 달러정기예금**(1:1): 골드 금리카드(4.2%·12개월·1천달러·상품명) + 코너 프레임 — 완성도 최고
