## 변경
`backend/app/gateway/design/steps.py`의 `_bake_prompt`에 "정보 밀도" 지시 추가:
- 금리·기간·금액을 **금리 하이라이트 카드**(둥근 컨테이너·그림자·악센트·큰 숫자 강조)로 디자인
- 여백·구분선·악센트 바·포인트 도형으로 편집 디자인 리듬
- **가드 유지**: 밀도는 레이아웃·도형·컨테이너·색으로만, 명시 카피 외 새 텍스트·숫자·라벨 금지(잔글씨 footgun 차단)

프롬프트만 변경 = 신 slot/모듈 없음(순수 최적화 경계), 롤백 쉬움.

## 결과 (강화 전 대비)
| | 강화 전 (live-real-api) | 강화 후 (이 폴더) |
|---|---|---|
| 금리 표현 | 밋밋한 한 줄 텍스트 | 구조화된 금리 하이라이트 카드 |
| 밀도 | 사진 + 텍스트 | 실제 은행 포스터급 컨테이너·악센트 |

- **B 청년도약적금**(4:5): 금리카드(2.80%+0.50%p→3.30%) 브래킷 악센트
- **C 달러정기예금**(1:1): 골드 금리카드(4.2%·12개월·1천달러·상품명) + 코너 프레임 — 완성도 최고

## 금융수치 그라운딩 (커밋 ea191ac)
초기 밀도 강화(29fdb97)에서 베이크 금리카드가 factsheet에 없는 수치를 **환각**하는 문제 발견
(튼튼: 3.5%→5.0%, 100만원→10만원). 원인=S2b 카피가 런별로 숫자를 누락해도 베이크가
factsheet를 못 받음. **이중 방어로 차단**:
1. S2a가 factsheet 수치를 결정론 추출 → `rate_card/{lang}.json` 정적 저장(진실원천)
2. `_bake_prompt`에 그 값 주입("이 수치만 정확히, 창작 금지")
3. 비전 게이트가 베이크된 카드 숫자를 정답과 대조 → 불일치=critical→재생성
검증: 튼튼 재생성 시 5.0%/10만원 → **3.5%/12개월/100만원 정확**.

## 최종 합성 (composite/) + 오버레이 폴리시 (커밋 aad9c7e)
`composite/`에 로고+고지를 얹은 최종 포스터(sceneAssembler 로직 재현): 공식 JB 로고 핀 +
금리카드 + 하단 법정 고지 스트립. 완결된 은행 포스터 품질.

폴리시 2건:
- **로고 대비**: 어두운 배경 위 네이비 로고가 묻히던 문제 → sceneAssembler `logoPlate`가
  로고 뒤에 밝은 라운드 플레이트를 깔아 배경 무관 가독성 확보(로고 락업 방식).
- **CTA/고지 겹침**: `_bake_prompt` 세이프존 강화(좌상단 로고 자리 밝게 비우기 + 최하단
  고지 스트립 예약, CTA는 그 위에)로 CTA가 고지 영역에 침범하지 않게 함. 튼튼 재생성으로
  겹침 해소 확인.
