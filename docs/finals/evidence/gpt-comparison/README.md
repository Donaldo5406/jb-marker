## 결과 요약

| 항목 | GPT (gpt-image-1) | 우리 파이프라인 |
|---|---|---|

## 결론 (정직)

**GPT가 한눈에 더 예쁘다** — 정합성은 우리가 아직 못 따라감. **그러나 은행 실무 기준으로 GPT는 실격**이다:
공식 로고 오타(금응그룹), **법정 고지가 깨져 법적으로 무효**(됴친만인), 수치 오타 — 게다가 **평면이라 고칠 수도 없다**.
우리 산출물은 덜 세련됐지만 **모든 글자가 정확하고(로고·고지·수치) 레이어로 편집 가능**해 실제 납품이 된다.

핵심 차별점: **AI가 예쁜 그림을 그리는 것**과 **금융기관이 실제로 쓸 수 있는 정확·편집 가능한 마케팅 시스템**은 다르다.
우리 파이프라인은 후자다(그라운딩·컴플라이언스·결정론 로고/고지·편집 레이어).
