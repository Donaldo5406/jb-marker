## 3. AI Agent 서비스 공통 요건

본선 제출 서비스는 아래 3요소를 반드시 포함해야 한다.

| 구분 | 내용 |
|------|------|
| **판단** | 입력·상황·데이터를 해석하여 상태, 위험, 우선순위 등을 도출 |
| **행동** | 판단 결과에 따라 다음 행동 선택 (추가 질문, 근거 조회, 수정안 생성, 알림, 요약, 예약 등) |
| **검증/개선** | 결과를 점검하고 필요 시 재시도 또는 종료 조건을 통해 품질 관리 |

## 4. 제출물

### 필수

1. **발표자료(PDF)** — 양식 제한 없음, 단 **배경 색 통일**(주최 측 배경색 PPT 제공). 필수 포함 항목:
   - Summary / 문제 정의 / 제안 솔루션 개요 / 주요 기능 정의 / 데이터 및 기술 활용 / 사용자 시나리오·유즈케이스 / 기대 효과 및 향후 확장성 / **본선 구현 결과 및 시연 계획** (← 예선 대비 추가 항목)
2. **기능명세서(PDF)** — 3p 이내 권장, 예선 제출본 기반. 필수 포함 항목:
   - 서비스 개요 / 시스템 구성도 / 핵심 기능 명세 / 주요 기능 흐름도 / **기능 변경이력** / 향후 발전 방향 / 부록
   - **기능 변경이력**: 예선 명세서 대비 추가·수정·삭제가 있으면 **변경 일자·변경 대상 기능·변경 내용·변경 사유·변경 전후 차이**를 기재. 변경 없으면 "변경 사항 없음" 기재 가능. 미기재·허위 기재는 실격 요건.
3. **GitHub 링크(URL)** — 코드 일체를 하나의 링크로. 저장소가 여러 개면 하나의 Repo에 링크 형식으로 연결.
   - 저장소에 포함할 것: 서비스 실행 코드 / README(실행 방법·환경 설정) / 주요 기능별 코드·모듈 / 사용 데이터·외부 API 설명 / 재현성 확인 자료
   - 🔴 **접근 권한 문제로 확인 불가 시 제출 누락으로 간주.**

### 선택

- **시연영상** — 5분 이내, 100MB 제한. 포함: 서비스 소개 / 핵심 사용자 시나리오 / 주요 기능 동작 / **AI Agent의 판단·행동·검증/개선 흐름** / 최종 결과 화면.
  - 🔴 **유튜브·Vimeo 등 검색 노출 가능한 공개 플랫폼 업로드 금지.**
- **데모웹링크**

### 유의

- 제출 자료는 비공개 게시(아이디어 유출 방지). 발표자료·기능명세서는 반드시 PDF.
- 운영진이 심사 확인용으로 코드·데모 링크·보완자료 추가 제출을 요청할 수 있음 — 기한·방식 준수.
