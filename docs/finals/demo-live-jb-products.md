# 라이브 시연 스크립트 — JB 실상품 (2026-07-04)

> 원칙: 이 문서에 금리·한도 수치를 적지 않는다(미검증 수치 창작 금지).
> 수치는 시연 중 Stage A 웹리서치가 조사하거나, 리허설에서 전북은행 공식 페이지로 확정한다.

## 시나리오: "JB 주거래 플러스 적금 — 직장인 타겟 캠페인"

1. BrainStorming 입력:
   "전북은행 JB 주거래 플러스 적금 캠페인. 타겟은 급여이체 직장인, 신뢰감 있는 톤,
    한국어·영어 2개 언어, 채널은 앱푸시·이메일."
2. Stage A 웹리서치가 상품 조건을 직접 조사 → 팩트시트·필수고지를 계약(plan.md)에 채움.
   (AskUser 토스트가 뜨면: 매체=이미지 선택)
3. Design: 브랜드 컨텍스트(JB 네이비·따뜻한 금융 톤)가 자동 반영됨을 언급 —
   "저희가 JB CI를 팩으로 심어서, 지시 없이도 JB답게 나옵니다. 물론 사용자가 지정하면 그게 우선입니다."
4. Review→Deploy는 기존 데모 흐름 그대로.
